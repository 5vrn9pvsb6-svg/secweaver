# 08. 调查场景说明

**语言：** [English](08-investigation-scenarios.md) | 简体中文（本文）

SecWeaver 使用 Scenario Pattern 描述常见安全调查场景。你可以把它理解成给 AI 使用的“调查剧本”。

---

## 为什么需要调查场景？

不同问题的调查路径不同。

例如：

- 查外部攻击 IP，要从 IP 开始。
- 查 WebShell，要从 WAF / Web 访问 / 文件和命令开始。
- 查横向移动，要从主机、账号、登录和防火墙开始。
- 查数据外传，要从外连、DNS、流量和数据库审计开始。

如果不定义场景，大模型可能每次都用不同方式查，结果不稳定。

Scenario Pattern 的作用是告诉系统：

```text
这个问题属于哪类调查？
从哪个字段开始？
先查什么？
再查什么？
用哪些 Join 规则？
默认查多长时间？
```

---

## S1：外部 IP 溯源

### 适合的问题

```text
这个攻击 IP 有没有打进来？
这个 IP 最早访问了哪个业务？
它是否导致主机异常？
有没有后续横向移动？
```

### 常见输入

- `attacker_ip`
- `alert_time`
- `time_start` / `time_end`

### 常查数据

- WAF 告警
- Web 访问日志
- 主机命令执行
- SSH 登录
- 防火墙日志
- 资产清单

### 典型链路

```text
攻击 IP
→ WAF 告警
→ Web 访问日志
→ 主机命令执行
→ SSH 登录 / 防火墙访问
→ 影响范围
```

### 输出重点

- 是否有攻击请求。
- 是否到达业务。
- 是否出现主机行为。
- 是否发生横向移动。
- 第一台受害主机是谁。

---

## S2：WEB 入侵 / WebShell

### 适合的问题

```text
这个 Web 告警是不是打穿了？
有没有 WebShell 落地？
攻击请求后主机有没有执行命令？
```

### 常见输入

- `src_ip`
- `url`
- `alert_time`
- `host`

### 常查数据

- WAF 告警
- Web 访问日志
- 主机命令执行
- 文件操作
- 主机外连

### 典型链路

```text
WAF 告警
→ Web 访问命中
→ 主机命令执行
→ 文件写入 / 外连
```

### 输出重点

- 是否误报。
- 攻击请求是否到达后端。
- 是否产生命令执行。
- 是否出现 WebShell 文件。
- 是否出现可疑外连。

---

## S3：横向移动追踪

### 适合的问题

```text
这台主机有没有继续访问其他内网主机？
攻击者有没有从 Web 服务器横向到数据库？
某个 IP 是否参与横向移动？
```

### 常见输入

- `host`
- `host_ip`
- `user`
- `src_ip`
- `alert_time`

### 常查数据

- SSH 登录
- 防火墙日志
- 主机命令执行
- 资产清单
- Network / Host 信息

### 典型链路

```text
受害主机
→ SSH 登录 / 防火墙访问
→ 目标主机
→ 目标主机命令执行
→ 影响范围
```

### 输出重点

- 是否跨主机访问。
- 是否跨网段访问。
- 是否从低信任区进入高信任区。
- 涉及哪些账号。
- 横向路径是什么。

---

## S4：告警确认

### 适合的问题

```text
这条告警是真实攻击还是误报？
有没有攻击成功？
是否需要升级处置？
```

### 常见输入

- 告警内容
- `src_ip`
- `url`
- `alert_time`
- `rule_id`

### 常查数据

- WAF 告警
- Web 访问日志
- 主机命令执行
- 主机外连
- 文件操作

### 典型链路

```text
WAF 告警
→ Web 访问上下文
→ 主机执行 / 文件 / 外连
→ 判断是否成功
```

### 输出重点

- 告警是否误报。
- 是否真实攻击。
- 是否攻击成功。
- 证据链是什么。
- 是否需要封禁、隔离或继续观察。

---

## S5：主机行为风险识别

### 适合的问题

```text
这台主机上有没有高危命令？
对外监听进程有没有执行异常命令？
有没有可疑外连或文件操作？
```

### 常见输入

- `host`
- `host_ip`
- `time_start` / `time_end`

### 常查数据

- 主机命令执行
- 主机外连
- 文件操作
- Host 暴露面信息

### 典型链路

```text
对外监听服务
→ 命令执行
→ 外连 / 文件操作
→ 风险等级
```

### 输出重点

- 是否有高危命令。
- 是否和对外暴露服务相关。
- 是否有下载、反连、持久化行为。
- 风险等级和处置建议。

---

## S6：账号失陷追踪

### 适合的问题

```text
这个账号是不是被盗用了？
这个账号从哪里登录？
登录后做了什么？
```

### 常见输入

- `user`
- `src_ip`
- `host`
- `alert_time`

### 常查数据

- SSH 登录
- 主机命令执行
- Windows 事件日志
- Linux 系统日志
- 资产清单

### 典型链路

```text
账号
→ 登录来源
→ 登录主机
→ 后续命令执行
→ 横向或影响范围
```

### 输出重点

- 是否异常登录。
- 登录来源是否异常。
- 是否登录多台主机。
- 登录后是否执行敏感命令。
- 是否需要禁用账号或重置凭证。

---

## S7：数据外传追踪

### 适合的问题

```text
这台主机有没有向外传数据？
有没有异常大流量外连？
数据库数据是否被访问后外传？
```

### 常见输入

- `host`
- `host_ip`
- `dst_ip`
- `domain`
- `time_start` / `time_end`

### 常查数据

- 主机外连
- DNS 日志
- 网络流量审计
- 数据库审计
- 文件操作

### 典型链路

```text
主机
→ DNS 解析
→ 外连会话
→ 大流量传输
→ 数据库访问 / 文件访问
```

### 输出重点

- 是否访问可疑外部 IP 或域名。
- 是否出现异常大流量。
- 是否有敏感数据库访问。
- 是否有压缩、打包、上传行为。
- 是否证据足以确认外传。

---

## S8：C2 通信检测

### 适合的问题

```text
这台主机的可疑外连是否与 C2 通信有关？
反弹 Shell 命令与外连目标能否关联起来？
这些 DNS 查询能否解释可疑回连域名？
```

### 常见输入

- `host` / `host_ip`
- `dst_ip` / `domain`
- `time_start` / `time_end`（带时区的起止时间）

### 常查数据

- P0：主机外连 `host_connect`，至少包含 `host`、`dst_ip`、`dst_port`、`timestamp`。
- P1：网络流量审计或代理日志、DNS 日志、主机命令执行，用于补充会话、域名及进程上下文。
- P2：系统风险告警，补充主机侧线索。

P0/P1/P2 是数据完整性需求优先级，具体字段要求见[数据源完整性分析](15-data-source-completeness.zh-CN.md)。

### 典型链路

```text
主机外连
→ 目标 IP / 域名
→ DNS 与流量 / 代理会话上下文
→ 同主机命令执行与系统风险告警
```

### 技能入口与输出重点

先使用 `data-source-completeness` 检查 S8，再在未被阻塞时进入
[`risk-identification`](19-risk-identification.zh-CN.md)。需要继续还原跨主机攻击链时，转交溯源分析。

- 给出可疑外连及关联命令的证据引用、严重级别和调查建议。
- 区分已观察到的风险与仍需补充证据的 C2 怀疑，不能仅凭外连或域名判定主机失陷。
- DNS 只能补充域名解析，不能替代会话方向、字节数和代理动作证据。
- 缺少 P0 数据时先补数据；没有命中不代表主机安全。

## 场景和数据源的关系

| 场景 | 最关键数据源 |
|---|---|
| S1 外部 IP 溯源 | WAF、Web、主机执行、SSH、防火墙 |
| S2 WEB 入侵 | WAF、Web、主机执行、文件、外连 |
| S3 横向移动 | SSH、防火墙、主机执行、资产清单 |
| S4 告警确认 | WAF、Web、主机执行、文件、外连 |
| S5 主机风险 | 主机执行、外连、文件、Host 暴露面 |
| S6 账号失陷 | SSH、系统日志、主机执行 |
| S7 数据外传 | 外连、DNS、流量、DB 审计、文件 |
| S8 C2 通信检测 | 主机外连、流量或代理日志、DNS、主机执行、系统风险告警 |

---

## 如何选择场景？

如果你不确定，可以这样判断：

| 你手里的线索 | 推荐场景 |
|---|---|
| 一个攻击 IP | S1 |
| 一条 WAF 告警 | S4 或 S2 |
| 一个可疑 URL | S2 |
| 一台异常主机 | S5 或 S3 |
| 一个账号 | S6 |
| 外连 IP / 域名伴随疑似数据上传 | S7 |
| 可疑回连、反弹 Shell 或 C2 IP / 域名 | S8；同时怀疑外传时叠加 S7 |
| 想查完整攻击链 | S1 + S2 + S3 |

大模型可以辅助选择场景，但最终能查什么取决于你配置的数据资产。
